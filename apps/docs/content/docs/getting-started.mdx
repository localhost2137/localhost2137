---
title: Getting started
description: Run a Slack bot against an isolated local workspace, change its behavior, and repeat the test.
---

In this tutorial, you will run an ordinary Slack Bolt bot without a Slack account, workspace, or
credentials. A test will create a local workspace, send `ping` as a user, and verify that the bot
posts `pong` through Slack's normal Web API boundary.

You need Node.js 24 or later and pnpm.

## Clone the executable example

Run this outside an existing project:

```sh
pnpm dlx localhost2137 demo clone slack-ping-bot ./slack-ping-bot
cd ./slack-ping-bot
```

The clone command creates a standalone pnpm project and installs its dependencies. Its target must
be new or empty; it refuses to replace existing files.

Run the test:

```sh
pnpm test
```

The final summary should contain:

```text
Test Files  1 passed (1)
Tests       1 passed (1)
```

No daemon or Slack setup remains after the command. The test owns a temporary runtime, workspace,
callback server, and storage directory, then closes them.

## Follow the local world

Open `test/ping-pong.test.ts`. Its config installs one Slack emulator with deliberately local
credentials and sends Events API callbacks to the bot:

```ts
const config = defineConfig({
  services: {
    slack: slack({
      config: {
        botToken: "xoxb-local-ping-pong",
        eventsUrl: `http://127.0.0.1:${botPort}/slack/events`,
        signingSecret: "local-ping-pong-signing-secret",
        workspaceName: "Ping Pong Local",
      },
    }),
  },
});
```

The test runtime binds an OS-assigned loopback port and creates one empty, isolated instance:

```ts
const runtime = await createTestRuntime({
  config,
  port: 0,
  storage: "temporary",
});
const instance = await runtime.createInstance();
```

The next calls arrange a user and channel through operations. They control the local workspace; the
application itself does not depend on them.

```ts
const ada = await instance.slack.createUser({ name: "Ada" });
const channel = await instance.slack.createChannel({ name: "general" });
await instance.slack.addUserToChannel({
  channel: channel.id,
  user: ada.id,
});
```

`buildPingPongBot` receives the selected instance's connection values. Inside `src/bot.ts`, Bolt is
configured with the local Web API URL, token, signing secret, and callback path:

```ts
const app = new App({
  clientOptions: { slackApiUrl: options.apiUrl },
  endpoints: "/slack/events",
  signingSecret: options.signingSecret,
  token: options.botToken,
});

app.message(/^ping$/, async ({ say }) => {
  await say("pong");
});
```

The operation below represents Ada typing in Slack. It persists `ping` and delivers a signed Slack
event to the bot. Bolt handles that event and posts `pong` through `chat.postMessage`.

```ts
await instance.slack.sendMessage({
  channel: channel.id,
  from: ada.id,
  text: "ping",
});
await instance.idle();
```

`idle()` waits for tracked callback work. The final operation then observes both messages in the
same workspace:

```ts
const messages = await instance.slack.listMessages({ channel: channel.id });
expect(messages.map(({ text }) => text)).toEqual(["pong", "ping"]);
```

The `finally` blocks destroy the instance and close the runtime even when an assertion fails.

## Change the bot and repeat

In `src/bot.ts`, change the reply:

```ts
await say("pong from localhost2137");
```

Update the expectation in `test/ping-pong.test.ts`:

```ts
expect(messages.map(({ text }) => text)).toEqual([
  "pong from localhost2137",
  "ping",
]);
```

Run the same test again:

```sh
pnpm test
```

It passes against a new empty workspace. The previous test cannot supply users, channels, messages,
or callback state to this run.

You have now exercised one complete local-service loop: operations arranged and triggered the
world, the application received and sent provider-shaped traffic, and an operation inspected the
result. [Operations and emulated APIs](/operations-and-apis) explains why those boundaries are
separate.

[Integration testing](/testing) to design tests around your own application.
